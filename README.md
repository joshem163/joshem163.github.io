# Formal Academic Website

This package converts the original single-page dark portfolio into a restrained, multi-page academic website suitable for GitHub Pages or a custom domain.

## Pages

- `index.html` — Home / About
- `research.html` — Research program and selected projects
- `publications.html` — Selected publications grouped by year
- `talks.html` — Invited talks, conference presentations, and posters
- `teaching.html` — Teaching and mentorship
- `gallery.html` — Academic photographs
- `contact.html` — Contact details and professional profiles

The HTML intentionally uses the same asset filenames as the original website, so an existing `assets/` folder can be merged into this package.

## GitHub Pages

1. Replace the old site files with the contents of this package.
2. Keep all HTML files in the repository root.
3. Keep CSS and JavaScript in `assets/css/` and `assets/js/`.
4. Add the image and CV files listed above directly inside `assets/`.
5. Commit and push the changes.
